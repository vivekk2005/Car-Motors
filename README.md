# 🚗 A-One Motors Driving School Website

A modern, interactive 3D driving school web application built with React, Three.js (React Three Fiber & Drei), Tailwind CSS, Framer Motion, and Vite.

## ✨ Features

- **Interactive 3D Car & Highway**: Real-time 3D interactive car visualization using Three.js and React Three Fiber.
- **Modern Responsive Design**: Fully responsive UI styled with Tailwind CSS, supporting dark/light mode.
- **Smooth Animations**: Animated transitions and interactions powered by Framer Motion.
- **Course & Package Catalog**: Detailed driving courses, instructor profiles, and package pricing.
- **Booking & Advisor System**: Interactive booking modal and course advisor assistant.
- **Customer Reviews & Gallery**: Testimonials, trust factors, and visual showcase.

## 🛠️ Tech Stack

- **Framework**: [React 18](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **3D Graphics**: [Three.js](https://threejs.org/), [@react-three/fiber](https://docs.pmnd.rs/react-three-fiber), [@react-three/drei](https://github.com/pmndrs/drei)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Motion & Icons**: [Framer Motion](https://www.framer.com/motion/), [Lucide React](https://lucide.dev/)

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn / pnpm

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/vivekk2005/<repo-name>.git
   cd <repo-name>
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
